## English

A feature-rich 4chan image board viewer for iOS and Android, built with Flutter.

### Features

- **Boards Management**: Browse and favorite boards for quick access
- **Flexible Views**: Switch between grid and list view for boards
- **Sortable Boards**: Organize boards according to your preference
- **Fast Media Gallery**: Quick image and video viewing with WebM support on iOS
- **Media Downloads**: Download images and videos (WebMs automatically converted to MP4)
- **Batch Downloads**: Download all images from a board at once
- **Dark Mode**: Full support for system dark mode
- **Multi-Language**: Support for English and Chinese (Simplified)
- **Bookmarks**: Save and manage your favorite threads
- **Persistent Settings**: All your preferences saved across app restarts

### Installation

#### TestFlight (iOS)

If you want to test it on TestFlight, use [this link](https://testflight.apple.com/join/ky5bRwMY)

#### Build from Source

1. Clone the repository:
```bash
git clone https://github.com/NekoSurf/NekoSurf.git
cd NekoSurf
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

### Multi-Language Support

The app supports multiple languages with persistent language selection:
- English
- Chinese (Simplified) - 简体中文

To change the language, go to **Settings → Language** and select your preferred language. The app will automatically update and remember your choice.

## 中文

一个功能丰富的 4chan 图片板浏览器，适用于 iOS 和 Android，使用 Flutter 构建。

### 功能特性

- **板块管理**：浏览并收藏板块以便快速访问
- **灵活视图**：在网格视图和列表视图之间切换
- **可排序板块**：根据您的偏好组织板块
- **快速媒体画廊**：快速图片和视频查看，iOS 支持 WebM
- **媒体下载**：下载图片和视频（WebM 自动转换为 MP4）
- **批量下载**：一次性下载板块中的所有图片
- **深色模式**：完全支持系统深色模式
- **多语言**：支持英语和简体中文
- **书签**：保存和管理您喜欢的主题
- **持久化设置**：所有偏好设置在应用重启后保存
